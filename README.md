 🎮 LAN Multiplayer Tic-Tac-Toe

A Java Swing-based multiplayer Tic-Tac-Toe game that allows two players to play against each other over a Local Area Network (LAN) using TCP sockets.

 Features

- Two-player LAN multiplayer.
- Real-time move synchronization.
- Custom player usernames.
- Live chat between players.
- Modern dark gaming interface.
- Player turn indicators.
- Live scoreboard.
- Winner and draw announcements.
- Restart game functionality.

 ▶️ How to Run

 Requirements
- Java JDK installed.
- Two computers connected to the same network (for LAN multiplayer).

Steps

1. Clone or download this repository.
2. Open the project folder.
3. Open the terminal inside the `src` folder.
4. Compile the Java files:

   `javac *.java`

5. Run the application:

   `java Main`

6. Start a game and connect another player using the host computer's LAN IP address.
